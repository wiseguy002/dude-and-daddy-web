Classroom

Spooky stuff, school-friendly.

Three short activities that use the game’s own writing. No sign-in, no accounts, nothing to install. The game is rated 11 and up, so check it fits your class first.

Activities

1. Write a PA announcement

Read the store-announcement bar at the top of this site. Write five new announcements in the same silly-but-polite voice. Which one is funniest read aloud?

2. Write an employee file

Open Meet the Staff. Pick a character and write a new file for them: a job title, a one-line bio and a catchphrase.

3. Read the patch notes

Open What’s new. How do the notes make updates fun? Write your own notes for something in school.

Tech notes

  • The pages need only a web browser, and the game plays on computers, phones and tablets.
  • Solo play needs no internet once it has loaded. Leaderboards and co-op do need it.
  • The game and this site have no accounts, no ads and no tracking. See the privacy page and the page for parents.
  • Your school’s network rules decide whether the game opens, so please test before class.
